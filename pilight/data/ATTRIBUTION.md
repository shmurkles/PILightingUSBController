# Data attribution

`cities15000.tsv` is derived from the [GeoNames](https://www.geonames.org/) `cities15000`
dump (`download.geonames.org/export/dump/cities15000.zip`), trimmed to five columns
(`name`, `country`, `lat`, `lon`, `timezone`) out of the original nineteen. Downloaded and
trimmed 2026-08-10.

GeoNames is licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
This attribution file satisfies that license's attribution requirement for the redistributed
subset in this repository.
